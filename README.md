## **Assignment Features**

- Modern student portfolio with a **light lavender theme**.
- **Responsive hero section** with decorative shapes.
- **Sticky navigation bar** for easy section navigation.
- Student introduction and **profile cards**.
- **Skills section** featuring HTML, CSS, and JavaScript.
- **Education section** with university and course details.
- **Projects section** with sample project descriptions.
- **Contact section** with email and GitHub links.
- CSS positioning using `position: sticky`, `position: absolute`, and `position: fixed`.
- Layered decorative elements using `z-index`.
- **Flexbox** for navigation, cards, buttons, and responsive layouts.
- **CSS Grid** for the skills section and information panels.
- **CSS box model** using margin, padding, border, and `box-sizing: border-box`.
- **Hover effects** and **smooth scrolling**.
- Fixed **back-to-top button** using JavaScript.
- **Automatic footer year** using JavaScript.
- Responsive **desktop, tablet, and mobile** layouts.
- **Semantic HTML** elements for better structure and accessibility.

```text
shubham-student-portfolio/
```

All HTML, CSS, and JavaScript code is contained in a **single `index.html` file**. No separate CSS or JavaScript files are required.

## **How to Run**

1. Open the project folder in **VS Code** or **GitHub Codespaces**.
2. Open `index.html`.
3. Run it using **Live Server**, if available, or open the HTML file in a browser.
4. Test the **navigation links**, **contact links**, and **back-to-top button**.
5. Resize the browser window to check the **responsive layout**.

**No external libraries or build tools are required.**
